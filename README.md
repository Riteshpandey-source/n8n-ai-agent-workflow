# AI Agent Workflow Automation using n8n

## Overview
A hands-on AI Agent workflow prototype built using n8n Cloud during its free trial. The project explores conversational AI, memory management, external search integration and tool-based automation.

## Workflow Architecture

The workflow consists of the following components:

1. **Chat Trigger:** Receives conversational messages from users.
2. **AI Agent:** Processes user queries and coordinates connected tools.
3. **Simple Memory:** Maintains conversational context.
4. **SerpAPI:** Provides external search capabilities.
5. **Calculator:** Handles mathematical operations through the agent.

## Key Features
- Conversational AI interactions.
- Context-aware conversations using memory.
- External information retrieval.
- Tool-assisted mathematical calculations.
- Visual workflow orchestration.
